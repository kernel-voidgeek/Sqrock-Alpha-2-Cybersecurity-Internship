 Day 10 - Local Honeypot Tracker

**Name:** Christian Adam Anilbhai

## Project Overview
A local Flask-based honeypot demonstration
that records incoming HTTP requests for
security monitoring and analysis.

## Features
- Local honeypot server
- HTTP request monitoring
- Timestamp logging
- IP address logging
- Requested path tracking
- User-agent collection
- Alert generation

## Technologies
- Python
- Flask
- HTTP
- JSON

## Security Concepts
- Honeypot monitoring
- Reconnaissance detection
- Request logging
- Security alert analysis

## Disclaimer
The application runs locally for educational
purposes. Recorded requests are from the
controlled training environment.
