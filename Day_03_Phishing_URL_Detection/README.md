
# Day 3 - Python Phishing URL Detection

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based phishing URL detection tool that
assigns risk scores to URLs using predefined
security indicators.

## Features
- URL analysis
- Risk score calculation
- Low, Medium and High risk classification
- Suspicious keyword detection
- IP address URL checks

## Technologies
- Python
- URL parsing
- Regular Expressions

## Sample Results
- github.com - LOW RISK
- wikipedia.org - LOW RISK
- paypal-login.evil.com - MEDIUM RISK
- secure-account-update.example.com - HIGH RISK

## Disclaimer
Educational project only. Risk scores are heuristic
indicators and do not prove whether a website is malicious.
