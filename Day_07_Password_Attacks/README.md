
# Day 7 - Local Password Security Lab

**Name:** Christian Adam Anilbhai

## Project Overview
A local password security simulation demonstrating
failed login attempts and rate-limiting protection.

## Features
- Local Flask login application
- Failed login tracking
- Login attempt monitoring
- Rate limiting
- Security alert generation

## Technologies
- Python
- Flask
- Requests
- HTML

## Security Concepts
- Brute-force attack prevention
- Account protection
- Login monitoring
- Rate limiting

## Disclaimer
Only the local training application is tested.
No external accounts or systems are targeted.
