
# Day 14 - Social Engineering Incident Response

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based incident response simulation
for a fictional high-severity phishing incident.

## Incident Details
- Incident type: Phishing
- Severity: HIGH
- Affected user: Fictional training account

## Response Actions
- Simulate account lockout
- Simulate session revocation
- Notify SOC team
- Preserve email logs
- Simulate email quarantine
- Simulate sender domain blocking
- Scan attachments in sandbox

## Features
- Incident classification
- Severity assessment
- Response action selection
- JSON incident report
- Text summary generation

## Technologies
- Python
- JSON
- Datetime

## Disclaimer
All response actions are simulated.
No real accounts or email systems are modified.
