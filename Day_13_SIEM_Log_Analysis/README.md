
# Day 13 - SIEM Log Analysis System

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based SIEM log analysis demonstration
that identifies suspicious login activity and
email rule changes from sample security logs.

## Activities
- Failed login analysis
- IP address extraction
- Failed attempt counting
- Suspicious email rule detection
- Security alert generation

## Sample Findings
- User: admin
- Failed attempts: 2
- Suspicious email rule: forward_all
- Alert severity: HIGH

## Technologies
- Python
- Log analysis
- Text processing

## Security Concepts
- SIEM fundamentals
- Authentication monitoring
- Suspicious activity detection
- Alert investigation

## Disclaimer
Uses sample training logs. Findings are
demonstrations, not live security incidents.
