
# Day 9 - Fake Profile Detection System

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based fake profile detection demonstration
that assigns risk scores to sample profiles.

## Features
- Profile risk scoring
- Multiple sample profile analysis
- High and Low risk classification
- Output report generation

## Technologies
- Python
- Conditional logic
- JSON or text file handling

## Sample Results
- user_001 - 100/100 HIGH RISK
- user_002 - 0/100 LOW RISK
- user_003 - 80/100 HIGH RISK
- user_004 - 20/100 LOW RISK
- user_005 - 0/100 LOW RISK

## Disclaimer
This is a rule-based educational demonstration,
not a verified method of identifying fake accounts.
