
# Day 12 - Phishing Email Detection using Machine Learning

**Name:** Christian Adam Anilbhai

## Project Overview
A machine learning project that classifies email
messages into phishing and legitimate categories.

## Features
- Email text preprocessing
- Text feature extraction
- Phishing email classification
- Legitimate email classification
- Model evaluation
- Accuracy calculation
- Confusion matrix

## Technologies
- Python
- Scikit-learn
- CountVectorizer
- Multinomial Naive Bayes

## Dataset
- 25 phishing email samples
- 25 legitimate email samples

## Machine Learning Concepts
- Natural Language Processing
- Supervised learning
- Text classification
- Model evaluation

## Disclaimer
Educational demonstration using sample data.
Reported accuracy is not representative of
real-world phishing detection performance.
