
# Day 4 - Vishing Awareness Training

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based vishing awareness training project
that generates fictional voice-based social
engineering scenarios.

## Scenarios
- IT Support impersonation
- Bank representative impersonation
- Government officer impersonation

## Features
- Example call scripts
- Warning sign identification
- Safe response suggestions
- Psychological trigger analysis
- Defensive security lessons

## Technologies
- Python
- Text file generation

## Disclaimer
All scenarios are fictional and intended for
security awareness training only.
