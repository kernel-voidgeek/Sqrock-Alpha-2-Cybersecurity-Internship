
# Day 5 - OSINT Target Profile Analysis

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based tool that collects and organizes
publicly available GitHub profile information
for an OSINT training exercise.

## Information Analyzed
- Public GitHub username
- Public display name
- Organization information
- Public location and bio, when available
- Public repository count
- Programming languages in recent repositories

## Features
- GitHub profile analysis
- JSON profile generation
- Potential security risk identification
- Security recommendations

## Technologies
- Python
- GitHub public profile information
- JSON

## Disclaimer
Only public information is considered.
Use OSINT techniques ethically and responsibly.
