
# Day 8 - USB Drop Attack Simulation

**Name:** Christian Adam Anilbhai

## Project Overview
A Python-based USB drop awareness simulation
that collects basic local system information
for a controlled training demonstration.

## Information Collected
- Timestamp
- Hostname
- Operating system
- OS version
- Current user
- Working directory

## Features
- Local system information collection
- Reconnaissance log generation
- Text-based output
- Simulation status reporting

## Technologies
- Python
- Platform
- Socket
- OS
- Datetime

## Disclaimer
Educational simulation only.
No data was transmitted externally.
